# FlashFormula

Formula flashcards for first-year engineering - the formulas keep escaping, so catch them one card at a time.

**Live:** https://kanishksaini-007.github.io/FlashFormula/

## What it does

- Built-in deck of 21 cards across physics, math and chemistry (equations of motion, quadratic formula, ideal gas law and friends)
- Tap a card to flip it and reveal the formula plus what every symbol means
- Mark "I know this one" or "Still learning" - progress bar tracks how much of the deck you have mastered
- Shuffle the deck, filter by subject, add your own cards
- Everything stays in your browser (localStorage) - no account, no sync, no tracking

## Stack

One `index.html` file. Plain HTML, CSS and JavaScript, no frameworks, no build step.

## Run it

Open the live link above, or serve the folder locally:

```
python -m http.server
```
